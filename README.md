# Zakázkový list – Dílná

Jednoduchá PWA webová aplikace pro rychlé vytvoření servisního požadavku na telefonu i počítači.

## Funkce
- datum
- termín dokončení
- editovatelný zadavatel
- číslo klíče
- volitelná SPZ, motor a výkon v kW
- servisní požadavek
- fotografie vozidla / místa
- vygenerování PDF
- sdílení PDF přes systémové sdílení (na iPhonu lze vybrat WhatsApp)
- možnost přidání na plochu iPhonu jako PWA

## Spuštění
Jde o statický web. Stačí ho nasadit na libovolný HTTPS hosting.

Poznámka: přímé automatické odeslání souboru do konkrétní WhatsApp skupiny běžná webová aplikace neumí bez WhatsApp Business API. Tlačítko „Vygenerovat a sdílet“ používá systémové sdílení iOS.
